# SRS — Спецификация требований

**Продукт:** ИС планирования меню на неделю.
**Команда:** Николаев И. О., Лебедев А. В.
**Источник:** обследование предметной области (ПИС) + интервью с заказчиком (Столовая ФГБОУ ВО УдГАУ).

## 1. Назначение

Система предназначена для составления меню на неделю из базы блюд и автоматического формирования списка покупок.

## 2. Глоссарий

| Термин | Определение |
|--------|-------------|
| Блюдо | Единица меню с набором ингредиентов |
| Ингредиент | Продукт, входящий в блюдо |
| Меню на неделю | Набор блюд, распределённых по дням недели |
| Список покупок | Агрегированный перечень ингредиентов из меню |
| Порция | Количество единиц блюда |

## 3. Функциональные требования (ФТ)

**ФТ-1.** Система должна показывать базу блюд с возможностью выбора блюда на день.
**ФТ-2.** Система должна сохранять выбранное блюдо в меню на выбранный день недели.
**ФТ-3.** Система должна отображать меню на неделю по дням.
**ФТ-4.** Система должна формировать список продуктов из ингредиентов меню.
**ФТ-5.** Система должна позволять указывать количество порций для блюда.
**ФТ-6.** Система должна пересчитывать список продуктов с учётом количества порций.
**ФТ-7.** Система должна отображать список покупок.
**ФТ-8.** Система должна искать блюда по названию.
**ФТ-9.** Система должна позволять добавлять пользовательские блюда.
**ФТ-10.** Система должна экспортировать список покупок в файл.

## 4. Нефункциональные требования (НФТ)

**НФТ-1.** База блюд открывается не дольше 2 с при 500 записях.
**НФТ-2.** Список продуктов формируется не дольше 3 с при меню на 7 дней.
**НФТ-3.** Система доступна не менее 99 % времени в учебные дни.
**НФТ-4.** Данные пользователя сохраняются между сессиями.
**НФТ-5.** Интерфейс работает в браузере без установки дополнительного ПО.
**НФТ-6.** Поиск блюд возвращает результат не дольше 1 с.
