# Пользовательские истории с критериями приёмки

## US-1. Составление меню на неделю
Как пользователь, я хочу составить меню на неделю, чтобы планировать питание заранее.

**Критерий 1.** Дано: есть база блюд; когда пользователь выбирает блюдо на день; тогда блюдо сохраняется в меню на выбранный день.
**Критерий 2.** Дано: меню составлено; когда пользователь открывает страницу меню; тогда отображается меню по дням недели.

Метка: `must`. История: MENU-3.

## US-2. Генерация списка продуктов
Как пользователь, я хочу получать список продуктов на основе меню, чтобы покупать только нужное.

**Критерий 1.** Дано: меню на неделю заполнено; когда пользователь запрашивает список продуктов; тогда формируется агрегированный список ингредиентов.

Метка: `must`. История: MENU-4.

## US-3. Список покупок
Как пользователь, я хочу видеть список покупок, чтобы не забыть купить продукты.

**Критерий 1.** Дано: список продуктов сформирован; когда пользователь открывает список покупок; тогда отображается перечень продуктов с количеством.

Метка: `must`. История: MENU-5.

## US-4. Поиск блюд
Как пользователь, я хочу искать блюда по названию, чтобы быстро находить нужное.

**Критерий 1.** Дано: есть база блюд; когда пользователь вводит название; тогда отображаются подходящие блюда.

Метка: `should`. История: MENU-6.

## US-5. Пользовательские блюда
Как пользователь, я хочу добавлять свои блюда, чтобы учитывать личные рецепты.

**Критерий 1.** Дано: пользователь авторизован; когда он добавляет своё блюдо; тогда блюдо сохраняется и доступно в его списке.

Метка: `should`. История: MENU-7.

## US-6. Тестирование основных сценариев
Как тестировщик, я хочу проверить основные сценарии, чтобы убедиться в работоспособности.

**Критерий 1.** Дано: система собрана; когда выполняются основные сценарии; тогда все критические сценарии проходят без ошибок.

Метка: `must`. История: MENU-8.

## US-7. Указание количества порций (вброс заказчика)
Как пользователь, я хочу указывать количество порций, чтобы список продуктов был точным.

**Критерий 1.** Дано: блюдо выбрано в меню; когда пользователь указывает количество порций; тогда список продуктов пересчитывается.

Метка: `must`. История: MENU-9.

## US-8. Экспорт списка покупок (вброс заказчика)
Как пользователь, я хочу экспортировать список покупок в файл, чтобы распечатать его.

**Критерий 1.** Дано: список покупок сформирован; когда пользователь нажимает «Экспорт»; тогда файл со списком скачивается.

Метка: `should`. История: MENU-10.
