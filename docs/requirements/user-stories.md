# Пользовательские истории и требования

## US-01. Просмотр каталога рецептов
**Как пользователь,** я хочу просматривать каталог рецептов, чтобы выбирать блюда для меню.

*   **Сценарий 1 — каталог заполнен**
    *   **Given:** в системе сохранены рецепты.
    *   **When:** пользователь открывает каталог.
    *   **Then:** система отображает список рецептов с названиями и основной информацией.
*   **Сценарий 2 — каталог пуст**
    *   **Given:** в системе нет сохранённых рецептов.
    *   **When:** пользователь открывает каталог.
    *   **Then:** система сообщает, что рецепты отсутствуют.

Метка: `must`. 

## US-02. Поиск рецептов
**Как пользователь,** я хочу искать рецепты по названию, чтобы быстрее находить нужные блюда.

*   **Сценарий 1 — совпадения найдены**
    *   **Given:** в каталоге есть рецепт, название которого соответствует запросу.
    *   **When:** пользователь вводит запрос и запускает поиск.
    *   **Then:** система отображает подходящие рецепты.
*   **Сценарий 2 — совпадений нет**
    *   **Given:** в каталоге нет рецептов, соответствующих запросу.
    *   **When:** пользователь выполняет поиск.
    *   **Then:** система сообщает, что подходящие рецепты не найдены.

Метка: `must`. 

## US-03. Просмотр ингредиентов, расчёт порций и список покупок
**Как пользователь,** я хочу просматривать ингредиенты, задавать число порций, пересчитывать количества и формировать список покупок, чтобы планировать приготовление блюд и покупки продуктов.

*   **Сценарий 1 — просмотр ингредиентов**
    *   **Given:** в системе сохранён рецепт с ингредиентами и их количеством.
    *   **When:** пользователь открывает карточку рецепта.
    *   **Then:** система отображает ингредиенты и количества для исходного числа порций.
*   **Сценарий 2 — пересчёт порций**
    *   **Given:** пользователь открыл рецепт с указанным исходным числом порций.
    *   **When:** пользователь задаёт другое число порций.
    *   **Then:** система пропорционально пересчитывает количество каждого ингредиента и показывает обновлённые значения.
*   **Сценарий 3 — формирование списка покупок**
    *   **Given:** пользователь выбрал блюда для меню на неделю, а рецепты содержат ингредиенты и их количества.
    *   **When:** пользователь формирует список покупок.
    *   **Then:** система объединяет ингредиенты выбранных блюд в общий список и суммирует одинаковые ингредиенты, если единицы измерения совместимы.
*   **Сценарий 4 — экспорт списка покупок**
    *   **Given:** список покупок сформирован и отображается на экране.
    *   **When:** пользователь выбирает действие экспорта.
    *   **Then:** система создаёт файл со списком ингредиентов и их количеством и предоставляет возможность сохранить его.
    *   **And:** если список пуст, система сообщает, что экспортировать нечего, и не создаёт пустой файл.

Метка: `must`. 

## US-04. Редактирование собственного рецепта
**Как пользователь,** я хочу редактировать созданный мной рецепт, чтобы исправлять и обновлять сведения о блюде.

*   **Сценарий 1 — успешное редактирование**
    *   **Given:** пользователь открыл созданный им рецепт.
    *   **When:** он изменяет данные и сохраняет рецепт.
    *   **Then:** система проверяет обязательные поля и сохраняет изменения.
*   **Сценарий 2 — обязательные поля не заполнены**
    *   **Given:** пользователь редактирует собственный рецепт.
    *   **When:** он пытается сохранить рецепт без обязательных данных.
    *   **Then:** система не сохраняет изменения и указывает, какие поля нужно заполнить.

Метка: `should`. 

## US-05. Удаление собственного рецепта
**Как пользователь,** я хочу удалять созданные мной рецепты, чтобы поддерживать каталог в актуальном состоянии.

*   **Сценарий 1 — удаление подтверждено**
    *   **Given:** пользователь выбрал созданный им рецепт для удаления.
    *   **When:** он подтверждает удаление.
    *   **Then:** система удаляет рецепт и обновляет каталог.
*   **Сценарий 2 — удаление отменено**
    *   **Given:** система запросила подтверждение удаления.
    *   **When:** пользователь отменяет действие.
    *   **Then:** система оставляет рецепт без изменений.
*   **Сценарий 3 — рецепт используется в меню**
    *   **Given:** выбранный рецепт включён в меню на неделю.
    *   **When:** пользователь пытается его удалить.
    *   **Then:** система предупреждает о связи рецепта с меню и обрабатывает эту связь до завершения удаления.

Метка: `Could`. 

## US-06. Планирование меню на неделю
**Как пользователь,** я хочу составлять меню на каждый день недели, чтобы заранее планировать питание.

*   **Сценарий 1 — добавление блюда**
    *   **Given:** пользователь открыл меню на выбранную неделю и доступен каталог рецептов.
    *   **When:** пользователь выбирает рецепт и добавляет его на определённый день.
    *   **Then:** система отображает блюдо в меню соответствующего дня.
*   **Сценарий 2 — просмотр меню**
    *   **Given:** меню содержит выбранные блюда.
    *   **When:** пользователь открывает меню на неделю.
    *   **Then:** система отображает блюда, сгруппированные по дням.

Метка: `must`. 

## US-07. Изменение состава меню
**Как пользователь,** я хочу изменять состав меню, чтобы учитывать изменившиеся планы.

*   **Сценарий 1 — удаление блюда**
    *   **Given:** в меню на выбранный день есть блюдо.
    *   **When:** пользователь удаляет это блюдо.
    *   **Then:** система убирает блюдо из меню и показывает обновлённый вариант.
*   **Сценарий 2 — замена блюда**
    *   **Given:** пользователь хочет заменить блюдо в меню.
    *   **When:** он удаляет прежнее блюдо и добавляет другое.
    *   **Then:** система отображает обновлённый состав меню.

Метка: `must`. 

## US-08. Просмотр меню и списка покупок
**Как пользователь,** я хочу просматривать меню и связанный с ним список покупок, чтобы контролировать план питания и необходимые продукты.

*   **Сценарий 1 — просмотр меню**
    *   **Given:** пользователь сохранил меню на неделю.
    *   **When:** он открывает это меню.
    *   **Then:** система отображает сохранённые блюда по дням недели.
*   **Сценарий 2 — просмотр списка покупок**
    *   **Given:** для меню можно сформировать список покупок.
    *   **When:** пользователь открывает список покупок.
    *   **Then:** система показывает необходимые продукты и рассчитанные количества.

Метка: `Must`.
