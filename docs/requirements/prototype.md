# Эскизный прототип интерфейса

## Экран 1 — Меню на неделю

![Экран 1 — Меню на неделю](../Меню%20на%20неделю.png)

**Назначение:** составление, просмотр и редактирование меню по дням.

**Связанные истории:** 
US-06 — составить меню на неделю.
US-07 — удалить блюдо из ячейки меню.
US-08 — видеть меню на неделю в виде таблицы.
US-10 — очистить меню на неделю.

**Элементы:** панель кнопок, фильтр по категориям, таблица «Дата / День недели / Завтрак / Обед / Ужин / Перекус / Действия».

## Экран 2 — Список покупок

![Экран 2 — Список покупок](../Список%20покупок.png)

**Назначение:** просмотр, редактирование и экспорт списка покупок.

**Связанные истории:** 
US-11 — автоматически сформировать список покупок из меню.
US-12 — отмечать купленные продукты.
US-13 — видеть количество каждого продукта.
US-14 — добавлять свои продукты в список покупок.
US-15 — экспортировать список покупок.

**Элементы:** кнопки действий (сформировать, добавить, скопировать, .txt, CSV, печать, очистить), таблица «Наименование / Кол-во / Ед. / Действия», чекбоксы «куплено».

## Экран 3 — Справочник блюд

![Экран 3 — Справочник блюд](../Справочник%20блюд.png)

**Назначение:** просмотр, поиск и редактирование блюд.

**Связанные истории:** 
US-01 — добавлять свои рецепты.
US-02 — просматривать каталог рецептов с фильтрами.
US-04 — редактировать свои рецепты.
US-05 — удалять свои рецепты.

**Элементы:** поиск, фильтр по категориям, таблица «Название / Категория / Действия», кнопки ✏️ и 🗑.
