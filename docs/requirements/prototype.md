# Эскизный прототип интерфейса

Прототип выполнен в draw.io по реальному веб-приложению. 3 ключевых экрана.

## Экран 1 — Меню на неделю

![Экран 1](img/screen-1-menu.png)

Назначение: составление, просмотр и редактирование меню по дням.
Связанные истории: US-1, US-6, US-7.
Элементы: панель кнопок (дата, добавить день, случайное меню, добавить блюдо, справочники, избранное), средняя панель (сохранить, список покупок, очистить, тема), фильтр по категориям, таблица «Дата / День недели / Завтрак / Обед / Ужин / Перекус / Действия».

## Экран 2 — Список покупок

![Экран 2](img/screen-2-shopping.png)

Назначение: просмотр, редактирование и экспорт списка покупок.
Связанные истории: US-2, US-3, US-8.
Элементы: 7 кнопок (сформировать из меню, добавить позицию, скопировать, .txt, CSV, печать, очистить), таблица «Наименование / Кол-во / Ед. / Действия», чекбоксы «куплено» (купленные — зелёным, зачёркнуты), кнопки ✏️ и 🗑.

## Экран 3 — Справочник блюд

![Экран 3](img/screen-3-dishes.png)

Назначение: просмотр, поиск и редактирование блюд.
Связанные истории: US-1, US-4, US-5.
Элементы: поиск по названию, фильтр по категориям, таблица «Название / Категория / Действия», кнопки ✏️ и 🗑, чередование строк.
