# Протокол выбора базовой модели и ревью

## 1. Сравнение индивидуальных вариантов (Продвинутый уровень)
В рамках дисциплины ПИС были разработаны две индивидуальные модели предметной области:
- **Вариант Лебедева А.В. (IDEF0 + ER-first):** Детально проработаны процессы «как есть» и целевые функции (ЛР-03), структура сущностей БД (ЛР-02).
- **Вариант Николаева И.О. (Use-Case-first):** Акцент на сценариях взаимодействия пользователя с интерфейсом (UML).

**Решение:** За базовую принята модель Лебедева А.В. (IDEF0), так как она полностью соответствует требованиям ГОСТ и покрывает функциональные группы (A1-A4). Из модели Николаева И.О. заимствованы Use-Case сценарии для построения UML-диаграмм.
