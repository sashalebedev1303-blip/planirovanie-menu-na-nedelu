# C4 Модель архитектуры

В данном разделе представлена архитектура решения с использованием модели C4. Исходники диаграмм в формате PlantUML находятся в этой же папке.

## Уровень 1. Контекст

На данном уровне система рассматривается как «черный ящик». 
- **Актор:** Сотрудник столовой.
- **Система:** Веб-приложение «Планировщик меню».
- **Назначение:** Автоматизация процессов A1-A4 (IDEF0), сокращение времени планирования.

![C4 Level 1 - Контекст](c4-level1-context.PNG)

## Уровень 2. Контейнеры

Декомпозиция системы на основные технические компоненты. Выбрана монолитная архитектура (см. ADR-002).
1. **Веб-браузер (UI):** HTML, CSS, JS. Отвечает за ввод данных и визуализацию таблиц.
2. **Сервер приложений (FastAPI):** Python 3.11+. Обрабатывает бизнес-логику.
3. **База данных (SQLite):** Хранит сущности Dish, Ingredient, Menu, Shopping.
