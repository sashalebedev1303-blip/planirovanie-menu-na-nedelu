# ADR-002: Монолитная архитектура

**Статус:** Принято.
**Контекст:** 
*Связь с НФТ:* НФТ-2 (Список продуктов формируется не дольше 3 с), НФТ-5 (Работает в браузере без установки ПО).

**Решение:** Использовать монолит (Frontend + Backend на одном сервере FastAPI).
**Альтернативы:** Микросервисы (отклонены из-за сложности для команды из 2 человек).

**Последствия:**
- **Плюсы:** Единая кодовая база, отсутствие сетевых задержек между сервисами при расчете списка покупок (A3.2).
- **Риски:** Сложность выделения отдельных компонентов при росте проекта.
