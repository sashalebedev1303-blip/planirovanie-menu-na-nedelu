# ADR-001: Выбор СУБД (SQLite)

**Статус:** Принято.
**Контекст:** 
*Связь с НФТ:* НФТ-1 (База блюд открывается не дольше 2 с при 500 записях), НФТ-4 (Данные сохраняются между сессиями).

**Решение:** Использовать реляционную встроенную БД SQLite.
**Альтернативы:** PostgreSQL (отклонен из-за необходимости развертывания отдельного сервера).

**Последствия:**
- **Плюсы:** Мгновенный отклик (чтение с локального диска), простая миграция (один файл `.db`).
- **Риски:** Блокировка при одновременной записи. Принято, так как система локальная.
