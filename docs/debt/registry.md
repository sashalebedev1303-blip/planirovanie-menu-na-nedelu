# Реестр технического долга (docs/debt/registry.md)

ЛР-8, шаг 4–5. Формат по таблице 3 методички: каждая позиция с оценкой
затрат, эффектом от погашения и приоритетом. **Приоритет = эффект /
затраты** (какой эффект получаем на час работы): Высокий — эффект
многократно превышает затраты, Средний — сопоставим, Низкий — эффект
мал или отложен по срокам. Статус — отметка о погашении (шаг 5).
