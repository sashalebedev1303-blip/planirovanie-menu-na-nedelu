# Демонстрация «путь изменения» (ЛР-9)

Живой сценарий защиты: показываем, как одно изменение проходит путь
**коммит → pull request → конвейер → артефакт → образ → релиз**. Всё
выполняется на реальном репозитории, скриншоты — только как резервная копия
и приложение к отчёту (методичка: «мёртвые» скриншоты не засчитываются).

## Сценарий на 5–7 минут

| Шаг | Действие | Что показывает |
|---|---|---|
| 1 | `git switch -c demo/live-path` → правка → `git commit` → `git push` | изменение появляется в отдельной ветке, `main` не тронут |
| 2 | Открыть PR в `main` | GitHub запускает конвейер на событие `pull_request` |
| 3 | Вкладка **Checks** / **Actions → CI** | job'ы `lint → tests → build → docker` идут по цепочке `needs` |
| 4 | Открыть job `tests` | 43 теста и покрытие 100 % по ключевым модулям в логе |
| 5 | Открыть job `build` → **Artifacts** | артефакт `tastyweek-app` (zip) скачивается из прогона |
| 6 | Открыть job `docker` | образ собран, `docker run` + запрос `/api/menu` прошли |
| 7 | Вкладка **Releases → v1.0.0** | тег, заметки по разделам, прикреплённый архив |
| 8 | (при наличии Docker) `docker run` локально | приложение поднимается из того же образа, что собрал CI |
| 9 | PR с намеренно сломанным тестом | красный `tests` блокирует кнопку **Merge** (после настройки защиты ветки) |

## Резервный вариант (если сеть в аудитории недоступна)

1. Показать локальный прогон: `python -m ruff check .`, `python -m pytest -v`,
   `python scripts/build_release.py`, `docker build`/`docker run`.
2. Открыть заранее скачанные скриншоты из этой папки.
3. Открыть локальный файл `docs/release-notes/v1.0.0.md`.

## Команды для живой демонстрации

```bash
# 1. Изменение и коммит
git switch -c demo/live-path
# ... правка ...
git add -A && git commit -m "docs(lab9): демонстрационное изменение"
git push -u origin demo/live-path

# 2. После зелёного PR — локальная проверка артефакта
python scripts/build_release.py
python -m zipfile -l dist/tastyweek-app.zip

# 3. Локальный запуск образа
docker build -t tastyweek:demo .
docker run --rm -p 8000:8000 -e OPEN_BROWSER=0 tastyweek:demo
curl http://127.0.0.1:8000/api/menu
```

## Чек-лист перед защитой

- [ ] PR с демонстрационной веткой открыт, конвейер зелёный.
- [ ] Артефакт `tastyweek-app` доступен в прогоне.
- [ ] Образ `tastyweek:demo` собран и запускается локально.
- [ ] Релиз `v1.0.0` открывается, заметки на месте.
- [ ] Правила защиты `main` включены, красный PR блокирует слияние.
- [ ] Скриншоты `01`–`07` лежат в этой папке.
