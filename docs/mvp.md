### MVP — минимальный жизнеспособный продукт
**MVP** —  это наименьший набор функций, приносящий реальную ценность пользователю. Тест: *«Если выпустим только это — будет ли польза?»*

В нашем проекте MVP — это **релиз v0.1**.

#### Состав MVP

| ID | История | Почему в MVP |
| :--- | :--- | :--- |
| **US-01** | Добавление своих рецептов | Без наполнения базы своими рецептами пользователю не из чего будет составлять меню. |
| **US-02** | Каталог рецептов с фильтрами | Позволяет быстро ориентироваться в добавленных блюдах и выбирать нужные для планирования. |
| **US-03** | Указание ингредиентов и количества | Критически важно для автоматического формирования точного списка покупок. Высокий риск. |
| **US-06** | Составление меню на неделю | Ключевая функция планирования: без распределения блюд по дням система не заработает. |
| **US-07** | Удаление блюда из ячейки меню | Необходимая базовая механика для корректировки планов на неделю в случае ошибки. |
| **US-08** | Таблица меню на неделю | Визуальный интерфейс, без которого пользователь не сможет увидеть общую картину своего рациона. |
| **US-11** | Автоматический список покупок из меню | Главная ценность автоматизации: избавляет от ручного сбора ингредиентов. Высокий риск. |
| **US-12** | Отметка купленных продуктов | Базовый инструмент контроля в магазине, завершающий сценарий похода за покупками. |

**Итого:** 8 Must-историй.

#### Что НЕ входит в MVP
* **Should-истории** (`US-04`, `US-10`, `US-13`) — перенесены во второй релиз v1.0 для повышения удобства (редактирование рецептов, очистка меню и подсчет общего количества продуктов).
* **Could-истории** (`US-05`, `US-14`, `US-15`) — также перенесены в релиз v1.0, так как расширяют сценарии (удаление рецептов, добавление сторонних продуктов, экспорт списка), но не влияют на основной скелет системы.
* **Won't-история** (`US-09`) — push-уведомления отложены для следующей версии (v2.0) после пересмотра бэклога.
  
- MVP — это релиз v0.1: 8 Must-историй из эпиков E1–E3. Если выпустить только его, пользователь уже решает основную проблему — не думает каждый день, что готовить, и не забывает купить продукты. Значит, MVP приносит реальную ценность, а не является урезанным продуктом.
