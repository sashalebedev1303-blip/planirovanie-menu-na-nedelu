**Дата:** 23.09.2026  
**Автор:** `[Лебедев А. В.]`  

## Описание изменения

Добавить в форму выбора блюда поле «Количество порций» и пересчитывать список продуктов с учётом порций.

## Причина

Вброс заказчика в Спринте 1.

## Оценка влияния

- **На срок:** +8 ч на модуль меню, срок Спринта 3 не сдвигает.
- **На архитектуру:** Требуется изменение UI формы выбора блюда и логики пересчета ингредиентов; добавляются +2 теста.
- **На другие требования:** Затрагивает связанные сценарии вывода списка продуктов.
