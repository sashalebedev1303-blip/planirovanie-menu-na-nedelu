# ЗИ-1: Указание количества порций

**Описание:** добавить в форму выбора блюда поле «Количество порций» и пересчитывать список продуктов с учётом порций.
**Источник:** вброс заказчика в Спринте 1.
**Влияние:** +8 ч на модуль меню, +2 теста; срок Спринта 3 не сдвигает.
**Решение:** принято (владелец продукта Николаев И. О., 23.09.2026).
