# Матрица value/risk

Матрица уточняет порядок работ внутри категорий MoSCoW.
Must с высоким риском делаем в первом спринте — гипотезу проверяем рано.
Should с низким риском уходит в конец релизного плана.

## Пояснения

### Must + высокий риск

- **US-03** — модель данных рецепта влияет на точность списка покупок.
- **US-11** — агрегация ингредиентов и пересчёт при изменении меню.
Эти истории идут первыми в v0.1, чтобы рано проверить гипотезу.

### Must + низкий риск

- US-01, US-07, US-08, US-12 — понятные формы и таблицы, команда делала подобное.
Это надёжная ценность MVP.

### Should + высокий риск

- **US-13** — суммирование количеств. В MVP не входит, идёт в v1.0.

### Should / Could + низкий риск

- US-04, US-05, US-10, US-14, US-15 — уходят в конец релизного плана.

### Won't

- **US-09** — push-уведомления. Осознанно не делаем в этой версии.
