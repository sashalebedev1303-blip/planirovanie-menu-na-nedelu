# Иерархическая структура работ (ИСР / WBS)

## Принцип: декомпозиция по РЕЗУЛЬТАТАМ, а не по действиям

«Спроектированная база данных» — элемент ИСР,
«проектирование базы данных» — нет.

Все 14 пакетов исходной WBS (ЛР-3) переформулированы с действий на результаты.
