## Пояснение к столбцам

- **P (вероятность)** — 1–5, экспертная оценка команды
- **I (ущерб)** — 1–5, тяжесть последствий для проекта
- **Ранг** = P × I, приоритет внимания

## Стратегия реагирования

Для данного проекта преимущественно используется **снижение** риска:
- выделение отдельного пакета интеграции (WBS-9);
- парное владение критичными задачами;
- тест-кейсы и регрессия (MENU-8, WBS-11);
- фиксация требований и модели данных в репозитории.
