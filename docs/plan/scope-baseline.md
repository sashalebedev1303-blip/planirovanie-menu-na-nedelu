# Базовый план по содержанию (Scope Baseline)

Базовый план = ИСР + Словарь ИСР + Документ требований с трассировкой.

## 1. ИСР

См. `docs/plan/wbs.md`. Иерархия 1 → 2 → 3 → 4 → 5, коды 1.1…5.3,
все элементы названы результатами.

## 2. Словарь ИСР

Пять ключевых пакетов — в `docs/plan/wbs-dictionary.md` (разделы 1.1, 2.1, 2.2, 3.1, 4.1),
остальные — там же.

### Дыры (требование без пакета)

Не обнаружено — все R-01…R-17 закрыты элементами ИСР.

### Излишки (пакет без требования)

Формально пакеты 5.2 (релиз) и 5.3 (защита) не привязаны к конкретному
требованию к продукту. Это **организационные пакеты проекта**, оправданные
учебным процессом (сдача работы), а не требованиями к продукту.
Кандидатами на gold plating они не являются.

## 4. Контрольные вехи

- Защита — зачётная неделя
