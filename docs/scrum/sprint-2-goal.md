# Цель второго спринта

**Спринт 2:** 23.09–30.09

## Цель спринта

Превратить спроектированную основу в работающий функционал: генерация списка продуктов, список покупок, поиск блюд и пользовательские блюда.

## Взято в спринт: 21 поинт

После Спринта 1 в бэклоге осталось 26 поинтов (MENU-4 … MENU-8). Команда берёт 21 поинт — это соответствует velocity первого спринта (21 поинт).

| ID | История | Оценка |
|----|---------|--------|
| MENU-4 | Разработать генерацию списка продуктов | 8 |
| MENU-5 | Разработать список покупок | 5 |
| MENU-6 | Добавить поиск блюд | 3 |
| MENU-7 | Добавить пользовательские блюда | 5 |
| **Итого** | | **21** |

## Декомпозиция на задачи

| Задача | История | Критерий готовности | Оценка |
|--------|---------|---------------------|--------|
| Т-6. Реализовать агрегацию ингредиентов из меню | MENU-4 | Список продуктов формируется из меню | 3 ч |
| Т-7. Реализовать экран списка покупок | MENU-5 | Пользователь видит перечень продуктов | 2 ч |

## События спринта

**День 1 — вброс заказчика:** заказчик просит добавить экспорт списка покупок в файл.
Скрам-мастер защищает спринт: история уходит в бэклог продукта, в спринт не берётся.

**День 2:** оба участника на месте, работа идёт по плану.
