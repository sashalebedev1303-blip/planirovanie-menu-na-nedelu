## Чтение отчёта (по таблице 2 методички)

- **Дублирование.** 30 маршрутов FastAPI повторяют блок
  `db = SessionLocal() / try / … / finally: db.close()` (≈90 строк
  бойлерплейта) — вынесен в dependency `get_db` (Д-1).
- **Сложность.** Топ «до»: `init_db` (CC 21), `generate_random_menu` (12),
  `apply_favorite` (11), `get_report` (11), `aggregate_ingredients` (11).
- **Code smells.** Топ строгого профиля: B904 (raise без `from` внутри
  `except`), F401 (неиспользуемые импорты), I001 (порядок импортов), W291.
- **Покрытие.** Ключевые модули — 100 %; ограничение порога
  (`pytest.ini` меряет только `shopping_calc` и `quantity`) объяснено
  в разделе «Ограничения метрик» файла `docs/quality/before-after.md`.
- **Security hotspots.** SQL-конструирование проверено вручную: все
  запросы параметризованы (`text(...)` с bind-параметрами), инъекций
  не найдено; `random.choice` используется только в генераторе меню.
