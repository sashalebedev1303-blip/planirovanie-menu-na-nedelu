# Архитектура информационной системы «Планирование меню на неделю»

## 1. Общая архитектура приложения
Приложение построено по модульной монолитной архитектуре с использованием слоистой архитектуры (слои: маршрутизация/API, бизнес-логика, уровень работы с данными). 
* **Бэкенд:** Python, Flask, SQLAlchemy ORM
* **База данных:** SQLite (`dacha.db`)
* **Интерфейс:** Веб-приложение (HTML/CSS/JS, шаблонизатор Jinja2 или REST API)

---

## 2. Структура модулей и зоны ответственности

Проект разбит на следующие ключевые модули:

1. **Модуль работы с БД и моделями (`models.py`, `database.py`)**
   * **Ответственность:** Инициализация подключения к SQLite, определение схемы базы данных через SQLAlchemy (сущности: `Dish`, `Product`, `Ingredient`, `Menu`, `Shopping`, `Favorite`).
   * **Ключевые функции:** Управление сессиями БД, автозагрузка базовых справочников из `dishes.csv`.

2. **Модуль управления меню (`routers/menu.py` или внутри `main.py`)**
   * **Ответственность:** Создание, просмотр, редактирование и удаление записей меню на неделю по дням и приёмам пищи (`breakfast`, `lunch`, `dinner`, `snack`).
   * **Доп. функции:** Генерация случайного меню, дублирование меню на другие даты.

3. **Модуль управления блюдами и продуктами (`routers/dishes.py`)**
   * **Ответственность:** Ведение справочника блюд и продуктов, добавление пользовательских блюд с указанием ингредиентов, поиск и фильтрация по категориям.

4. **Модуль формирования списка покупок (`routers/shopping.py`)**
   * **Ответственность:** Автоматический сбор ингредиентов из выбранного меню, суммирование повторяющихся позиций с приведением единиц измерения и учётом количества порций (`Menu.servings ≥ 1`).
   * **Доп. функции:** Ручное редактирование списка, отметка позиций как «куплено», экспорт в CSV/TXT.

5. **Модуль поиска и фильтрации**
   * **Ответственность:** Обеспечение быстрого поиска блюд по названию и категории, фильтрация ингредиентов.

## 3. Структура каталогов проекта

Фактическая структура проекта и локального репозитория организована следующим образом:

```text
TastyWeek/
├── .venv/                   # Виртуальное окружение Python (включает Lib, Scripts, Include)
├── __pycache__/             # Кэш компилятора Python
├── build/                   # Временные файлы сборки (PyInstaller)
├── dist/                    # Итоговый дистрибутив программы (содержит исполняемый файл TastyWeek.exe)
├── main.py                  # Главная точка входа приложения (Flask)
├── dacha.db                 # Файл базы данных SQLite
├── dishes.csv               # Начальный справочник блюд и продуктов (CSV)
├── requirements.txt         # Зависимости Python для установки
├── start.bat                # Пакетный файл для быстрого запуска приложения в Windows
├── DachaApp.spec            # Спецификация сборщика PyInstaller
├── build_app.py             # Скрипт автоматической сборки приложения
└── README.md                # Описание проекта и инструкция по запуску
