# Архитектура информационной системы «Планирование меню на неделю»

## 1. Общая архитектура приложения
Приложение построено по модульной монолитной архитектуре с использованием паттерна MVC / слоистой архитектуры (слои: маршрутизация/API, бизнес-логика, уровень работы с данными). 
* **Бэкенд:** Python, FastAPI, SQLAlchemy ORM[cite: 3, 6]
* **База данных:** SQLite (локальное хранение)[cite: 3]
* **Интерфейс:** Веб-приложение (HTML/CSS/JS, шаблонизатор Jinja2 или REST API)[cite: 3]

---

## 2. Структура модулей и зоны ответственности

Проект разбит на следующие ключевые модули:

1. **Модуль работы с БД и моделями (`database.py`, `models.py`)**
   * **Ответственность:** Инициализация подключения к SQLite, определение схемы базы данных через SQLAlchemy (сущности: `Dish`, `Product`, `Ingredient`, `Menu`, `Shopping`, `Favorite`).
   * **Ключевые функции:** Управление сессиями БД, миграции, автозагрузка базовых справочников из `dishes.csv`.

2. **Модуль управления меню (`routers/menu.py` / `menu_module`)**
   * **Ответственность:** Создание, просмотр, редактирование и удаление записей меню на неделю по дням и приёмам пищи (`breakfast`, `lunch`, `dinner`, `snack`).
   * **Доп. функции:** Генерация случайного меню, дублирование меню на другие даты[cite: 2, 3].

3. **Модуль управления блюдами и продуктами (`routers/dishes.py` / `dishes_module`)**
   * **Ответственность:** Ведение справочника блюд и продуктов, добавление пользовательских блюд с указанием ингредиентов, поиск и фильтрация по категориям[cite: 2, 3].

4. **Модуль формирования списка покупок (`routers/shopping.py` / `shopping_module`)**
   * **Ответственность:** Автоматический сбор ингредиентов из выбранного меню, суммирование повторяющихся позиций с приведением единиц измерения и учётом количества порций (`Menu.servings ≥ 1`)[cite: 2, 3].
   * **Доп. функции:** Ручное редактирование списка, отметка позиций как «куплено», экспорт в CSV/TXT[cite: 2, 3].

5. **Модуль поиска и фильтрации (`routers/search.py`)**
   * **Ответственность:** Обеспечение быстрого поиска блюд по названию и категории, фильтрация ингредиентов[cite: 2, 3].
